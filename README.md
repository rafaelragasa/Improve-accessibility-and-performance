# SecureNotes accessibility and performance lab

This project contains a static landing page for the SecureNotes lab exercise and a GitHub Actions workflow for automated validation.

## Files

- `index.html` – accessible semantic structure and lab content
- `styles.css` – contrast, layout and styling updates
- `script.js` – minimal enhanced interaction for the review button
- `assets/*.svg` – placeholder illustrations used by the page
- `.github/workflows/ci.yml` – CI pipeline for running the tests
- `tests/` – accessibility and performance checks

## Verification

Open `index.html` in a browser and confirm the page renders with the expected structure, the button changes to `Review started`, and the images include meaningful alt text and dimensions.
